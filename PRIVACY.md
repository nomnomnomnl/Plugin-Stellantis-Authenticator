# Privacy policy

This extension collects no data.

- It only has access to the Stellantis login domains (`idpcvs.peugeot.com`, `idpcvs.citroen.com`, `idpcvs.driveds.com`, `idpcvs.opel.com`, `idpcvs.vauxhall.co.uk`).
- On those domains it reads only the redirect address at the end of the login, to extract the one-time OAuth code. It then shows that code on a page inside the extension.
- The code is never stored, logged or sent anywhere. It goes to your clipboard only when you click **Copy**.
- It has no analytics, tracking or remote code, and it makes no network requests of its own.
